Results

What a memory of the home did, in simulation.

Before building anything for real sites, we wanted one question answered: if a robot could read a simple, persistent memory of the place it works in, would it do its job better? We ran that as a controlled simulation. This page is the setup, the numbers, and what they do not show.

Setup

The same robot, the same homes, twice.

We simulated a household robot working through everyday tasks: putting things away, fetching things, moving between rooms, following the household's instructions. Each home has its own layout, its own preferences and its own rules.

Every task was run in two conditions with the same model, the same homes and the same task list:

Without memory
The robot starts each task knowing only what its training taught it. Nothing about this home carries over from one task to the next.
With memory
The robot can read a simple text memory of this home before and during the task. The memory is written by the home, not by the robot's model, and persists across tasks.

What the memory held

Deliberately simple.

We used the plainest memory that could work, so that any improvement is due to the fact of having one, not to a clever representation.

Preferences

How the household likes things done: which shelf the glasses go on, when the family eats, what stays where.

Rules

What the robot must not do in this home: rooms not to enter after a certain hour, things not to move.

Object locations

Where the robot last placed or saw an object.

Location probabilities

Where an object is most likely to be, when it has been seen in several places.

Measurements

Three questions, three numbers.

01 · Does it finish more tasks?

A task counts as completed only if the end state matches what was asked, including the household's preferences. A glass put on the wrong shelf is not a completed task.

+19 points · Tasks completed successfully

02 · Does it break fewer rules?

A rule violation is any task during which the robot did something the home had forbidden, whether or not the task was otherwise completed. With memory, the rules were served to the robot with every task.

None · Tasks with a rule violation

03 · Can a new robot inherit it?

This is the test that matters for the idea. We took a robot that had never been in the home, gave it the memory written during the previous robot's time there, and ran the same tasks. If memory belongs to the place, the new robot should be as good as the old one on day one.

Inherited · It performed up to par with the robot that had lived there

What this does not show

Read these as a reason to test on site, not as a promise.

  • It is a simulation. Real homes and warehouses are messier, sensors are noisier, and people move things without telling anyone. That is exactly what the on-site pilots are for.
  • The memory was the simplest possible. Plain text, no learned representation. We expect a better memory to do better, but we have not measured that here.
  • One environment type. Households. Warehouses and mixed fleets, where several robots of different makers write into one memory, are the next thing to measure.
  • One model. The same model in both conditions. The point was to isolate the effect of memory, not to compare models.
