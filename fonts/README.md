# Fonts

Self-hosted, latin subset only, served from this folder. No third-party requests.

| File | Family | Licence |
|------|--------|---------|
| `instrument-sans-var-latin.woff2` | Instrument Sans (variable, 400–700) | SIL OFL 1.1 — https://github.com/Instrument/instrument-sans |
| `geist-mono-400-latin.woff2` | Geist Mono 400 | SIL OFL 1.1 — https://github.com/vercel/geist-font |

Both are OFL fonts, so bundling them with the site is permitted. To swap a
family, replace the file and update the `@font-face` block at the top of
`style.css`.
