Persistent memory for robots

The place remembers.

Manens gives every environment its own ID, memory, history and context. Robots of any maker, and your LLM, query it. The place owns it, so it survives new models and new robots.

Product

Same robot. Same task. One of them knows the house.

A trained robot knows how to put glasses away. It doesn't know that this household keeps them on the left, top shelf. Without memory it does what its training suggests, and someone has to fix it. With Manens it reads the place's preference first.

The same holds for a warehouse: which bay a dock's pallets are staged in, which aisle is closed this afternoon, who yields to the forklift. The model is trained once. The place changes every day.

Results

What memory did, measured.

We ran a simulated household robot through 24,000 tasks, about 500 hours of simulation, twice: once with no memory, once with a simple text memory of the home's preferences, object locations and location probabilities. Same model, same tasks, same homes.

Tasks completed successfully

+19 points · The robot knew where things were and how the house liked them.

Tasks with a rule violation

None · The rules were served with every task, so none were broken.

A new robot, given the old robot's memory

Inherited · A robot that had never seen the home performed like the one that had lived in it.

Environment

Memory belongs to the place, not the robot.

Today, what a robot learns about a site lives in its weights or its context window, and is gone with the next model update. Manens turns that around: each environment gets an ID, and everything learned about that place lives under it.

Writes into it

  • Robots, any maker
  • Cameras and sensors
  • People: a rule, a preference, a closed aisle
  • The history of what changed, and when

Queries it

  • The planner of any robot, at the moment it acts
  • A mixed fleet, so two robots don't chase the same pallet
  • Your LLM, through an MCP connector
  • The next model, and the next robot, on day one

How it works

Plugs in beside the planner. Never touches the weights.

  1. 01

    Reads

    What robots, cameras and sensors see, and what people tell it.

  2. 02

    Serves

    Memory to the planner as simple tools: where, what changed, what's allowed.

  3. 03

    Checks

    Each step before it runs, against the site's rules. Allow or block, with a reason.
